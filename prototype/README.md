# prototype/ – the clickable demo

The first demo of Penka (Expo, fake data), built in November 2026 to agree on screens and flows.
It is **frozen**: we read it for ideas, we do not extend it. Real work happens in `app/`.

Live version: https://claude.ai/artifact/9cwFcmijMZsGG4hasnCXTU

Only this README is on GitHub. The demo code stays on your computer, because its sample data uses real class results from the CE report.

Run it: `npm install` then `npx expo start --web`.
