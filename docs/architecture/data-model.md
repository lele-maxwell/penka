# Data model

To be written before any backend code (Phase 0).

Main things we will store:
- School year, classes, teachers, the HOD
- Fiches de progression (lessons, hours) per class level
- Lessons marked as done, with date
- Séquence results per class: evaluated G/F, ≥ 10 G/F (optional class average)
- Generated reports

**Never stored:** student names, individual marks.
