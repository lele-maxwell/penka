# UI guidelines

## Colours
| Use | Colour |
|---|---|
| Main (sidebar, headings, buttons) | Deep navy `#172440` |
| Background | White |
| Accent | Steel blue `#34548F` |
| Charts: boys | `#3A5FA8` |
| Charts: girls | Ochre `#B8860B` |
| Charts: total | Grey `#A3ABBB` |

Never bright blue. Never pink. No background texture on the home page.

## Text
- Font: Plus Jakarta Sans. No serif or italic accent words.
- Sentence case for labels (not ALL CAPS).
- All interface text in French.
- Never "IA" or "l'IA". Use "Rédigé par le système" or "automatiquement".
- Write the brand as "Penka".

## Layout
- Navy sidebar.
- Dashboards show only the key numbers. Details go in the "Analyses et statistiques" tab.
- Penka has its own identity; do not copy another product's look.
